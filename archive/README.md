# Darkelf Documentation Archive

This directory contains historical Darkelf documentation retained for
project history, technical reference, and research purposes.

Archived documents may describe older Darkelf releases, experimental
configurations, superseded recommendations, or functionality that is no
longer present in current releases.

These documents are preserved for transparency and historical reference.

They should **not** be interpreted as current Darkelf Labs recommendations
or as descriptions of the latest Darkelf software.

For current information, refer to the root documentation and the
applicable project's latest release documentation.
