# Darkelf Labs — Attribution

## About

**Darkelf** is an open-source ecosystem of privacy-focused browsers, security software, developer tools, and technical documentation created and maintained by **Dr. Kevin Moore / Darkelf Labs**.

Current browser projects include:

- **Darkelf Cocoa** — native macOS privacy browser built with Python, PyObjC, Cocoa/AppKit, and WebKit.
- **Darkelf Shadow** — privacy-focused browser built with Python, PySide6, Qt, and Qt WebEngine.
- **Darkelf Docs** — documentation, technical research, guides, and project references.

## Authorship

Darkelf-specific architecture, privacy features, filtering systems, security tooling, interfaces, integrations, and documentation are developed and maintained by **Dr. Kevin Moore / Darkelf Labs**.
