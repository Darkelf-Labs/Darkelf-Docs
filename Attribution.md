About

Darkelf is an open-source ecosystem of privacy-focused browsers, security software, developer tools, and technical documentation created and maintained by Dr. Kevin Moore / Darkelf Labs.

Current browser projects include:

* Darkelf Cocoa — native macOS browser development using Python, PyObjC, Cocoa/AppKit, and WebKit.
* Darkelf Shadow — privacy-focused browser development using Python, PySide6, Qt, and Qt WebEngine.
* Darkelf Docs — technical documentation, research, guides, and project references.

Authorship

Darkelf’s original application architecture, privacy features, filtering systems, security tooling, interface design, integrations, documentation, and project-specific implementations are developed and maintained by Dr. Kevin Moore / Darkelf Labs.
